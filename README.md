# ★ XIN'S SPACE ★

贾新鑫的个人数字空间。项目使用 React + Vite 构建，视觉方向为 2008-2012 QQ空间、Y2K 与 2026 AIGC 创作者空间。

## 一键打开

双击 `启动作品集.bat`。脚本会在后台启动本地 Vite 服务，并自动打开：

`http://127.0.0.1:4188/`

## 开发命令

```powershell
pnpm install
pnpm run dev
pnpm run build
```

## 内容位置

- 页面与交互：`src`
- 头像、项目图、直播图、视频与音乐：`public/media`
- 真实内容策划与创作报告：`public/docs`
- 原始素材：`作品集codex`

音乐遵守现代浏览器规则，不会强制自动播放。点击首页 `ENTER XIN'S SPACE` 后，音乐会开始播放，并在站内切换页面时保持连续。
